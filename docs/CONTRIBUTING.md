# Contributing

This repository is a work-in-progress decompilation project.

## General guidelines

- Keep reconstructed source in `src/` and public headers in `include/`.
- Keep assembly/non-matching code in `asm/` until it can be replaced cleanly.
- Keep generated or reconstructed data definitions in `data/`.
- Put helper scripts in `tools/` and documentation in `docs/`.
- Do not commit ROM files or proprietary binary dumps.
- Prefer small, reviewable commits with clear matching/progress notes.
